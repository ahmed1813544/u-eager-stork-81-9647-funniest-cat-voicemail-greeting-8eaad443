Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty on make.fun.

`main.py` (stdlib only, deterministic) writes one line — the voicemail greeting a cat would record — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

Run it:

```sh
python3 main.py
```
